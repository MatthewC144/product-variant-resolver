# T43 Evidence — Final Priority-2 Research Batch

## Outcome and boundary

T43 verifies the checksum-bound T42 cumulative queue and selects every remaining pending priority-2
family in queue order. The final bounded slice contains nine families and thirteen Wiki release
rows. It is intentionally smaller than earlier ten-family batches; no synthetic tenth record is
added.

Six packets receive machine `create_new_casting` recommendations: Proton Saga, Small Bloc, Super
Twin Mill, The Vanster, Twin Mill Gen-E, and X-34 Landspeeder. Each has a dedicated single-casting
Wiki page plus an exact-name observation from another host. Nissan Skyline GT-R (BNR32), Power
Wheels Dune Racer, and Standard Kart receive machine holds.

Every reviewer field remains pending. All thirteen release rows remain variant-held, promotion
eligibility is zero, and no stable entity, canonical UUID, PostgreSQL row, runtime candidate,
calibration input, or evaluation label changes.

| Family | Evidence class | Why it remains held |

| Nissan Skyline GT-R (BNR32) | `homonymous_castings` | HYY72 belongs to the mainline lineage, but a separate opening-hood RLC JJY54 tool is also 1:64 and uses the same base display name. |

These classes preserve three different identity problems instead of reducing them to one generic
ambiguity label. Toy numbers identify the current release rows but do not, by themselves, define a
safe durable family key.

## Remaining risk and next gate

Remote source pages may change, independent collector catalogs can repeat upstream mistakes, and
text observations are not physical-tool inspection. The recommendation layer is not an owner
decision. T44 must present the exact six-create/three-hold packet for explicit confirmation while
keeping all release variants held. Stable review IDs and materialization remain a later design.
